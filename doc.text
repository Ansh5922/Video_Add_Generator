1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This project transforms the existing CrowdWisdom video agent into an end-to-end,
universal AI Video Ad Generation platform. Users can enter ANY product, brand,
service, or startup details (URL, product description, target audience, niche,
and campaign goal). The platform then orchestrates a 3-agent pipeline to:
  1. Research competitor ads and extract audience psychology & hooks.
  2. Write 3 cinematic, high-converting video ad scripts (Pain, Proof, Transformation).
  3. Render 1080p cinematic MP4 video ads featuring custom motion graphics, charts,
     relevant stock media, natural neural voiceovers, and Hollywood color grading.

The platform is exposed via a high-performance FastAPI backend with real-time SSE
progress updates and a clean, minimalist React SaaS frontend dashboard with review
checkpoints at every step.

3. USER EXPERIENCE & WORKFLOW (MULTI-STEP STUDIO)
--------------------------------------------------------------------------------
The user operates through an interactive 4-step studio with full review checkpoints:

STEP 1: CAMPAIGN ONBOARDING & INPUT FORM
- User enters:
  * Product / Brand Name (e.g. "FinPulse AI", "EcoClean", "SaaSMetrics")
  * Product URL / Landing Page
  * Product Description & Key Features
  * Target Audience / ICP (e.g., "Freelancers, 25-45, struggling with invoices")
  * Ad Goal (Sign-ups, Sales, Brand Awareness, Free Trial)
  * Visual Tone & Voice Choice (Deep Male, Clear Female, British, Conversational)
- User clicks "Start Deep Research"

STEP 2: RESEARCH & INSIGHTS CHECKPOINT
- Real-time SSE Kanban board tracks:
  [Scraping Meta Ads] -> [Ranking Competitor Ads] -> [Extracting ICP & Pain Points]
- User reviews:
  * Top scraped winning competitor ads (Ad copy, headlines, CTA, score)
  * Target Audience Persona (Daily frustration, biggest fear, buying triggers)
  * Proven emotional hooks & power keywords
- User can tweak or approve the insights, then clicks "Generate Ad Scripts"

STEP 3: SCRIPT REVIEW & STORYBOARD EDITOR CHECKPOINT
- Agent 2 generates 3 tailored cinematic scripts:
  * Script A: Pain-First Hook ("Tired of spending 5 hours doing manual invoices?")
  * Script B: Data-Proof Hook ("78% of freelancers lose money on unpaid bills...")
  * Script C: Transformation Hook ("What if your finances managed themselves?")
- User inspects each script's:
  * Hook line & hook emotion
  * Scene-by-scene storyboard (Visual action, narration sentence, timing)
  * Audio voiceover preview (synthesizes audio sample on demand)
  * Call to Action (CTA)
- User can edit any text, select which version(s) to render, and clicks "Render Video"

STEP 4: VIDEO RENDERING & CINEMATIC PREVIEW
- Agent 3 renders the video with live progress updates:
  * Frame Generation (Procedural branding + Stock imagery for scene context)
  * Matplotlib / Graphic rendering (Custom metrics tailored to product)
  * Neural Audio narration via Edge-TTS
  * FFmpeg assembly (Ken Burns motion, fade transitions, teal-orange grading)
- User watches the finished 1080p MP4 in the built-in video player.
- Download MP4 button and export options.


4. BACKEND API SPECIFICATIONS (FASTAPI)
--------------------------------------------------------------------------------
Base URL: http://localhost:8000/api

1. POST /api/campaign/init
   Request: { product_name, product_url, description, target_icp, goal, tone }
   Response: { campaign_id, status: "created" }

2. POST /api/campaign/{campaign_id}/research
   Triggers Agent 1 (Ads Manager Agent)
   Response: {
     winning_ads: [...],
     insights: { icp_profile, proven_hooks, winning_concepts, emotional_triggers }
   }

3. POST /api/campaign/{campaign_id}/scripts
   Request: { (optional edited insights) }
   Triggers Agent 2 (Script Agent)
   Response: {
     scripts: [
       { id: "v1", type: "A", name: "Pain-First", voiceover, storyboard: [...], cta },
       { id: "v2", type: "B", name: "Data-Proof", voiceover, storyboard: [...], cta },
       { id: "v3", type: "C", name: "Transformation", voiceover, storyboard: [...], cta }
     ]
   }

4. POST /api/campaign/{campaign_id}/render
   Request: { script_id: "v1", script_data: { ... }, voice: "en-US-ChristopherNeural" }
   Triggers Agent 3 (Video Agent)
   Response: { job_id, status: "rendering" }

5. GET /api/campaign/{campaign_id}/stream
   Server-Sent Events (SSE) endpoint:
   Emits real-time JSON packets:
   { agent: "Video Agent", task: "render_frames", progress: 65, message: "Composing scene 3..." }

6. GET /api/campaign/{campaign_id}/videos/{video_filename}
   File streaming endpoint to watch or download the rendered MP4.

7. GET /api/campaigns
   Lists previously generated campaigns and video assets.


5. MEDIA & RENDERING ENGINES
--------------------------------------------------------------------------------
A. Neural Voice Synthesis (Edge-TTS)
- 100% free, zero API key required, ultra-realistic human quality.
- Voices supported:
  * English US Male: `en-US-ChristopherNeural`
  * English US Female: `en-US-JennyNeural`
  * English UK Male: `en-GB-RyanNeural`
  * English UK Female: `en-GB-SoniaNeural`
- Fallback: gTTS (Google Text to Speech) and optional ElevenLabs API key.

B. Dynamic Visual Hybrid Engine
- Scene-Adaptive Imagery:
  * Script scenes describe visual hooks (e.g. "Frustrated person at laptop", "Modern tech office").
  * Backend queries Pexels/Unsplash free API (with offline aesthetic gradients as fallback)
    to retrieve high-resolution contextual background stills matching each scene.
- Dynamic Charts & Data:
  * If the script includes metrics (e.g., ROI, hours saved, accuracy), Matplotlib generates
    a custom dark/modern visualization specific to the user's product.
- Ken Burns & Compositing:
  * High-definition PIL typography with drop-shadows and subtle vignette.
  * FFmpeg zoom/pan filters, cross-fades, and teal-orange color grading curves.
